# 🎂 Chúc Mừng Sinh Nhật - Đạo Lý Giang Hồ 🎂

Một trang web chúc mừng sinh nhật hài hước và độc đáo lấy cảm hứng từ các trào lưu TikTok, kết hợp nhạc đạo lý giang hồ và khúc hát mừng sinh nhật!

## ✨ Tính năng nổi bật
- **No-scroll Viewport**: Tối ưu chuẩn tỷ lệ video dọc TikTok (9:16) trên điện thoại và tự động căn giữa lung linh trên máy tính, không cần cuộn trang.
- **Trình chiếu 3 ảnh**: Hiệu ứng chuyển động mượt mà với khung viền neon RGB đổi màu rực rỡ và huy hiệu phong cách chiến thần giang hồ.
- **Lồng ghép 2 bản nhạc**: 
  - Đạo lý giang hồ: *"Tiền ngoài xã hội nhiều lắm, bản lĩnh ra xã hội lấy tiền..."*
  - Khúc Hát Mừng Sinh Nhật: Phan Đinh Tùng (*"Ngày hôm nay ta cùng hợp hoan nơi đây..."*)
- **Hiệu ứng trái tim & hoa bay quanh viền**: Các chùm hạt sáng lấp lánh (sparkling bloom) liên tục lượn vòng quanh khung ảnh, để lại vệt bụi sao lấp lánh và không che mặt người trong ảnh.
- **Tặng tiền & Troll độc lạ**: Form nhập số tài khoản & tên ngân hàng để gửi quà cho đại ca, khi nhấn gửi sẽ hiển thị dialog bất ngờ:
  > **CÓ CC NÈ 8==D** 🤣🍆💀

## 🚀 Cách chạy trên máy tính
1. Clone repository về máy:
   ```bash
   git clone https://github.com/duyhai020703/chuc-mung-sinh-nhat.git
   ```
2. Mở trực tiếp file `index.html` bằng trình duyệt (Chrome, Edge, Cốc Cốc, Safari).
3. Hoặc khởi động server cục bộ bằng Node.js:
   ```bash
   node server.js
   ```
   Sau đó truy cập `http://localhost:3000/`.
